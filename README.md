# tango-hart

scadawire/tango-controls integration to Hart devices

# Structure

The integration makes use of the tango python binding to implement device driver functionality.
See also https://tango-controls.readthedocs.io/en/latest/development/device-api/python/index.html

The HART specific functionality is covered by the hart-protocol python package.
See also https://pypi.org/project/hart-protocol/
